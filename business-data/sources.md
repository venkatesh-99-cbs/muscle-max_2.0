# Sources

Track where each fact in products.json / faqs.json / policies.json /
business-info.json actually came from, once you replace the "TBD"
placeholders — e.g. "price + ingredient list: photographed off physical
product label on <date>", "delivery policy: confirmed with owner via
WhatsApp on <date>". This is what you'll point to if a judge asks how
you verified the chatbot isn't making things up.
